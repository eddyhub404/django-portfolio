# Django Portfolio Website

A personal portfolio website built with Django.

## Features

* Responsive design
* About section
* Contact page
* Project showcase
* GitHub and LinkedIn links

## Tech Stack

* Python
* Django
* HTML
* CSS
* Bootstrap

## Setup

```bash
git clone <repo-link>
cd project-folder
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```
